### Cara Penggunaan:
1. **Upload ke Supabase Storage (Opsi Utama Anda)**: Di Supabase Dashboard > Storage > Bucket `project-images`, buat folder `certificates` dan unggah berkas PDF dengan nama yang sama.
2. **Kirim langsung melalui chat**: Anda juga dapat mengirimkan berkas PDF sertifikat di sesi chat kapan saja.
3. **Simpan di folder lokal**: Taruh berkas PDF ke dalam folder `d:/Portofolio/certificates/`.
